# Мои договоры

Мобильное приложение на Flutter для создания и ведения договоров.

## Возможности

- Создание и просмотр договоров
- Редактирование договоров
- Указание дат начала и окончания
- Изменение статуса договора
- Поиск договоров
- Удаление договоров
- Локальное сохранение данных

## Технологии

- Flutter
- Dart
- shared_preferences

## Запуск проекта

Установите Flutter и выполните в терминале из папки проекта:

```bash
flutter pub get
flutter run
```

## Целевая платформа

Основная цель проекта — iOS (iPhone).
